## 4. 未解決の論点

- 企画案 A（ローグライク）を基本にしつつ、参考作品はアトリエ系（案 B 寄り）。さらに E-26 で「固定の拠点は飽きる」とあるため、「採取の場＝ダンジョン、拠点＝工房」の折衷も見直しが必要
- 好きな要素（自動化・戦術戦闘・キャラ育成・探索）のどれを MVP の核にするか
- 「ズル」をどこまで設計者が用意し、どこから MOD で作ってもらうか
- 手作業の錬金で品質を上げる「システム」の中身（パズル、特性の組み合わせなど）
- 本人のヒアリングはまだ続く（このメモに追記する）
