## 1. 方針

[テスト仕様書（反復 2）](test-spec-it02.md) の 1 章の方針をそのまま使う。加えて次のとおりとする。

| 項目 | 内容 |
|---|---|
| 戦闘のテスト | 盤面の座標、行動順、体力の期待値を表にしたケースで確かめる。設計書 2.4・2.5 節の計算例は、そのままテストケースにする（REV-010、REV-024） |
| 誤りのテスト | 誤りが重なるケースで、設計書に書いた検査の順どおりの誤り（`errors.Is`）が返り、状態が変わらないことを確かめる |
| 乱数のテスト | 同じシードで同じ結果になること、依頼の乱数が本体の乱数の並びを変えないことを確かめる（NFR-06） |
| ID の割り当て | 反復 2 と同じく、Issue ごとに使う番号の範囲を 2 章の各節に決める。範囲の中で 01 から詰めて使う必要はない |
