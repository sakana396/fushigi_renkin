## 1. 方針

[テスト仕様書（反復 1）](test-spec-it01.md) の 1 章の方針をそのまま使う。加えて次のとおりとする。

| 項目 | 内容 |
|---|---|
| ui の確認 | 検証方法が D（実演）の要求と画面の決まり（DES-UI-01〜05）は、Windows 版で操作して確かめる（手動）。異常系まで確かめたときだけ「合格」とする（REV-015） |
| tick の数え方 | 時間の進みを確かめるテストは、設計書の計算例（DES-GOL-08）のように、何回目の `Tick()` で何が起きるかを書く（REV-010、REV-017） |
| ID の割り当て | 並行作業で連番が重ならないように、Issue ごとに使う番号の範囲を 2 章の各節に決める。範囲の中で 01 から詰めて使う必要はない |
