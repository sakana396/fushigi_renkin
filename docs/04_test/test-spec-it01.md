# テスト仕様書（反復 1）

- 文書 ID: TST-IT01
- 版: 0.1（雛形）
- 対象: [反復 1 計画書](../iterations/it01/plan.md) の範囲、[設計書 DES-IT01](../03_design/design-it01.md)

## 1. 方針

| 項目 | 内容 |
|---|---|
| テストの水準 | 単体テスト（`go test`）。core と defload の規則を対象とする。ui は対象外（使い捨て前提のため、遊んで確認する） |
| テストケース ID | `TC-<要求ID>-<連番2桁>`（例: `TC-FR-ITM-04-01`） |
| 種別 | 正常・境界・異常。1 つの要求に最低 1 件ずつ考える |
| コードとの対応 | 表駆動テストのサブテスト名にテストケース ID を入れる |
| 決定性 | 乱数を使うテストは、シードを固定する（NFR-06） |

## 2. テストケース

要求ごとに節を分ける。担当者は自分の要求の節だけを書く。

| 列 | 内容 |
|---|---|
| ID | テストケース ID |
| 対象 | 設計 ID |
| 前提 | テスト前の状態 |
| 入力・操作 | 与える入力や呼び出す操作 |
| 期待結果 | 確かめる結果 |
| 種別 | 正常・境界・異常 |
