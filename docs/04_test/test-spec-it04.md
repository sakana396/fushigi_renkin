## 1. 方針

[テスト仕様書（反復 3）](test-spec-it03.md) の 1 章の方針をそのまま使う。加えて次のとおりとする。

| 項目 | 内容 |
|---|---|
| ランクのテスト | 設計書 1.2・1.4 節の計算例（評判の境界、2 段上がる納品）をそのままテストケースにする |
| 出来事のテスト | 設計書 2.2 節の計算例（Events 7 件、Log 6 件、剣士の攻撃のあとの添字 4〜6）をそのままテストケースにし、出来事の項目の値と盤面の写しを確かめる |
| 進行の検証のテスト | 設計書 5 章の集合 S_r の求め方について、通る例と誤りの例を境界ごとに作る |
| 手動テスト | 反復 3 の振り返りの対策として、「初めて遊ぶ人が、操作の結果を画面から読み取れるか」の観点を入れる |
| ID の割り当て | Issue ごとに使う番号の範囲を 2 章の各節に決める。範囲の中で 01 から詰めて使う必要はない |
| トレーサビリティ | 反復 3 と同じ（テスト仕様書（反復 3）1 章） |
