## 仕様適合の確認

- FacingTarget は DES-FLD-04 の選び方のまま、設備・区画・拾う場所・敵のマスを候補にした（DES-FLD-07）。地図の上にいなければ (Target{}, false)
- PickFacing は、戦闘中 → 拾う場所でない → 空 → 定義がない・あふれるの順に検査する。Rolls 回の抽選は gatherIntoInventory をそのまま使う。戻る tick は (地図, x, y) ごとに `Now + RespawnSeconds × 60`。場面を出ても日が変わっても続く。PickRemaining は状態を変えない（DES-PCK-01・02）
- Gather・FacingFixture・gatherReady・ErrGatherCooldown をなくした。ゴーレムの採取（DES-GOL-08）は変えていない
- StartBattleFacing は戦闘中の検査を先にし、そのあと StartBattle と同じ検査をする。戦闘中も Scene は採取地の地図のまま。負傷中でも採取地の地図に入れて拾える（C-03）
- EnterGather の検査の順（ErrNotInGather → ErrInBattle → ErrUnknownID → ErrLocked → ErrNoGatherMap）。到着のマスに出口の向きで立つ。採取地の地図の出口から、街の gather 行きの到着のマスへ移る
- NewWorld は街の開始位置で上を向き、Y は当たり判定の上端をマスの上端にそろえる（C-05、E-110）
- 計算例 F-1〜F-18 が、そのまま期待値になっている。失敗した操作は World 全体と乱数の状態を変えない（DES-WLD-01）
- 既存のテストの置き換えは、元の仕様書と test-spec-it06 に「反復 6 で変更」と書かれ、検査は弱くなっていない。テストケースの番号は #105 に割り当てた範囲に収まっている
- ui は API の置き換えと、EnterGather への接続（「行く」のボタン）だけ
