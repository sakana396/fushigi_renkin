- `go test` は core・defload・data・tools/tccheck が成功（ui と cmd/fushigi は、Linux 環境に X11 がなくビルドできないため対象外）

## 実装者からの提案と判断

| # | 提案 | 判断 |
|---|---|---|
| P-01 | 押せないボタンは `action=nil` で灰色に描き、当たり判定から外す | 設計の範囲内 |
| P-02 | 候補の一覧を在庫の下の別の枠に置き、それぞれページ送りする | 設計の範囲内（DES-UI-05 の方式に合う） |

## 補足

- 反復 1 の TC-IF-01-04 の「錬金を確定すると不足の理由が出る」は、「確定のボタンが押せず、予想欄に理由が出る」に変わった。UC-03 3a の「確定できない」に合うので、仕様どおりの変更として扱う
- レシピの一覧とゴーレムの割り当てには、まだ内部 ID（`potion_herb` など）が出る。DES-UI-05 として #33 で直す
