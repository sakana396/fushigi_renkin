# REV-004: 自動マージの導入

- 対象: ブランチ `it01/auto-merge`（AGENTS.md、CLAUDE.md、スキル implement-req、`.claude/settings.json`、PLAN-001 v0.3）
- 日付: 2026-10-14
- 起案: 開発者本人（「個人開発のため、マージも自動化して進める」）
- 作成: Claude Code
- 承認: 開発者本人
- 結果: 承認

## 決定

- エージェントは「自動マージの条件」（CI 成功、別エージェントによるレビューと記録、要求・設計の変更に対する人の承認、未承認の設計提案がないこと）を満たすとき、マージまで行う
- 要求・設計・企画の文書と ADR の変更は、自動化の対象外とし、引き続き人の承認を必須とする
- 権限: `gh pr merge * --merge` と `gh pr checks` を許可。force push の禁止は維持

## 理由

- 個人開発で、マージ待ちが進行の律速になっていた
- 文書を残す目的（要求と設計の判断を人が行い、その経緯を辿れること）は、要求・設計の変更に人の承認を残すことで守る
