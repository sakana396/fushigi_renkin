## 仕様適合の確認

- 採取地の一覧は ID 順に名前と「行く」（`EnterGather`）を並べる。解放前は「ランク n で解放」と出してボタンを出さない（DES-UI-26、C-04、UC-11 の 3b）。負傷中は「負傷中（残り n 秒）」を出し、入れる（UC-11 の 3c）。「採取」「探索する」のボタンはない
- 「街へ戻る」は (10, 76, 120, 28) で、一覧は y 112 から。街の出口の「採取地へ」はいつも明るい色で出し、下向きの矢印を重ねる（DES-UI-28 の U-3）
- 採取地の地図では、拾う場所を向いて決定のキーで `PickFacing`、敵を向いて `StartBattleFacing` を呼ぶ。拾った物と誤りは操作結果に出す。負傷中は残り時間を付ける（DES-UI-26、UC-01、UC-12 の 1a、UC-17 の 1b・1c）
- 空の拾う場所は同じ絵を不透明度 0.4 で描き、名前を「あと n 秒」にする（`PickRemaining`、切り上げ）。向いたマスだけ「E: 」を付けて明るくする
- 敵は最初の敵の ID で絵を選び、表にないユニットは色の四角に頭文字を描く。名前は 1 体なら名前、2 体以上なら「たち」を付ける（4.3 節）。水は青いマスに暗い青の縁を付ける（E-111）。岩は背景なしの灰色の岩をコードで描く（E-112）
- 出来事を見せ終えると、地図の上に「戦闘の結果」の窓を開く。勝ち負け、報酬、負傷の残り秒数、記録のページ送りを出し、Esc か「閉じる」で閉じる。主人公は戦闘の前と同じ位置にいる（DES-UI-29、IF-07、UC-12 の 7）
- 敵は勝っても負けても残り、また戦える（UC-12 の補足）
- #105 のあとに残った途中の状態（地図で拾えず戦えない、一覧に「探索する」が残る）は解消した。反復 6 の機能はこれでそろう
- core は変えていない。描画のない計算は `internal/ui/uimodel` にあり、表駆動の単体テストがある（REV-059 F-09）
- 期待値が変わる旧仕様書の手動テストには「反復 6 で変更」を付け、test-spec-it06 に置き換えの一覧を書いた。テストケースの番号は #108 に割り当てた範囲（着手時に足した。Claude Code）に収まり、3 か所でそろっている
