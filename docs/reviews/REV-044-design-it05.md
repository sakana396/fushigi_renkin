## 検証

- 文書だけの変更で、コードは変わっていない
- 設計書 2.8 節の計算例 1〜24 を 1 行ずつ検算し、すべて一致した。修正で足した例 25〜31 と、直した例 16 も、規則を写したスクリプトで計算して一致した
- 本体の地図 2 枚（DES-DAT-03）は DES-VAL-17〜23 を満たす。5.2 節の歩く距離 16 個は、塗りつぶしで計算した値と一致し、最大は 8
- カメラの計算: 表示枠は 1600 × 868 px。工房は 960 × 576 px で収まり、街は 1440 × 960 px で、縦に 92 px ずれる
- 当たり判定 64 単位は 1 マス 96 単位より小さく、上下左右に隣り合う床のマスへは必ず移れる。DES-VAL-23 の塗りつぶし（上下左右）と合う
- Kenney の Tiny Town・Tiny Dungeon の 132 枚のタイルについて、`Tiles` の画像と `tilemap_packed.png` の切り出しが一致することを照合した。同梱の License.txt で CC0 1.0 と確かめた
- `go run ./tools/tccheck` は整合 OK（警告は手動テスト）
