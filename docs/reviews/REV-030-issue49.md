## 検証

- `gofmt -l .` は出力なし。`GOOS=windows go vet ./...` は成功
- `go test` は core・defload・data・tools/tccheck が成功（Linux では ui と cmd/fushigi を X11 がないためビルドできない）
- `go run ./tools/tccheck` は整合 OK
- 値が DES-DAT-01 の目安と一致することを確かめた（採取 5〜25、店 15、探索 40〜90、ユニット 4 種、3 種の消耗品の段階、盤面 8×6、負傷 60 秒、仲間の位置）
- 序盤の品質を検算した。回復薬 20〜40、全粒粉のパン 13〜33、ダブルのハンバーガー 29〜36、爆弾 15〜35
- 依頼の報酬はどれも、品質 20 で売った代金より多く、店で材料を買った額を下回らない。店の素材だけで作れるレシピはなく、店で買った素材を売ると損をする
- DES-BTL-02・03 をまねたシミュレーションで、消耗品なしで両方の採取地の戦闘に勝てることを確かめた（剣士の残りの体力 14〜21）
- ゴーレム 1 体目は洞窟の素材だけで作れ、工房 60・140、市場 70 にも、売却と依頼で届く
- TC-FR-MOD-02-26 を直したあと、採取地の品質の上限を変えるとこのテストが失敗することを Claude Code が確かめた

## 開発者に遊んで確かめてほしい点（仮置きの値。振り返りで聞く）

| # | 点 |
|---|---|
| D-1 | 序盤の製品は品質 13〜40 で、目安の「20〜30」より幅が広い。全粒粉のパンは下限 13 で、品質 20 以上の依頼を満たさないことがある |
| D-2 | 序盤の戦闘は消耗品なしで楽に勝てる。探索に再使用待ちがないので、戦闘が手間だけで高品質の素材を得る方法になり、消耗品の出番が少ないかもしれない |
| D-3 | ひかり苔の品質が他の採取素材と同じになり、珍しさは出やすさ（重み）だけで表される |
| D-4 | 序盤の売値は以前のおよそ半分。施設の費用の引き下げと依頼の報酬で釣り合うか |
| D-5 | ハンバーガーの依頼は、肉を店で買うと利益が 10〜20 しかない |
