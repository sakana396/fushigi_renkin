# REV-050: Issue #89（ui: 地図の画面と窓、場面のタブをなくす）のレビュー

- 対象: ブランチ `it05/89-map-ui`（Issue #89。実装 8178e86、修正 7ae9e90）
- 日付: 2026-10-16
- 実装: Codex（指摘の修正も Codex）
- レビュー: spec-reviewer（仕様適合レビュー）。Windows 版の手動確認は別のエージェント
- 承認: 不要（要求・設計・企画の文書と ADR は変更していない）
- 結果: 指摘を修正し、Windows の手動確認がすべて合格したので承認

## 検証

- `gofmt -l .` は出力なし。`GOOS=windows go vet ./...` と `GOOS=windows go build ./cmd/fushigi` は成功
- `go test` は core・defs・defload・data・ui/assets・tools/tccheck が成功（ui と cmd は X11 がないため Linux ではビルドしない）
- `go run ./tools/tccheck` は整合 OK（警告は手動のテストだけ）
- 4.1 節のフレームの流れ: F11・F12 → 出来事の再生 → 窓（Esc）→ 地図の上 → クリックの順。`MovePlayer` は時間の倍率のループの外で、1 フレームに 1 回だけ呼ぶ（DES-TIME-02）。窓を開いている間は移動・E・スペースを受け付けない。地図の上ではクリックは何もしない
- DES-UI-14: 切り出しの範囲は ((n mod 12)×16, ⌊n/12⌋×16)。読み込みに失敗したら `ui.Run` が誤りを返す
- 4.3 節: W の端、^ の段と端、設備・出入り口の絵、下地の選び方は表どおり
- DES-UI-16: 工房は (320,146) の位置で動かない。街は横 80 px の位置で中央に置かれ、縦は −92〜0 px の範囲でずれる。地図は帯に重ねない
- DES-UI-17: 絵の下端は当たり判定の下端と一致する。左向きは反転する。上下は直前の左右を引き継ぐ
- DES-UI-19・4.4 節: 欄を +42 し、素材候補・手作り錬金・割り当ての下端は 935。ボタンの当たる範囲も +42。6 種類の窓の欄は表どおり
- DES-UI-20・21: 帯の表示、案内の文の切り替え、起動時の文は設計どおり。「街へ戻る」は戦闘中と再生中に出ない。タブはなくなった
- Windows の手動確認: 最初の版（8178e86）で 33 件を行い、30 件合格・3 件不合格（TC-FR-FLD-01-40・42、TC-IF-08-53。R-01 と同じ原因）。修正後（7ae9e90）、不合格の 3 件、追加の 7 件、期待結果を変えた 3 件をやり直し、全 40 件が合格した。反復 3・4 の機能（錬金、売買、ゴーレム、施設、納品とランクの知らせ、探索と戦闘の出来事の再生）が窓の中で動くことも確かめた

## 指摘と対応

| # | 指摘 | 区分 | 対応 |
|---|---|---|---|
| R-01 | 地図の上の名前をマスのループの中で描いているため、右と下のマスで上書きされて欠ける（「ゴーレムの作業台」が「ゴーレム」になる）。錬金釜の下から上を向くと「E: 錬金釜」が主人公の頭に隠れる（DES-UI-15、DES-UI-17、UC-16） | 設計どおりへの修正 | 名前を、すべてのマスと主人公を描いた後にまとめて描き、暗い下地を付けて表示枠の中に収めた。手動確認で欠けも隠れもないことを確かめた |
| R-02 | TC-FR-FLD-02-40 の錬金釜の座標が (10,5) になっている。本体の地図では (9,5) | 設計どおりへの修正 | 直した |
| R-03 | 手動テストに、斜めと逆向きのキー、壁に沿って滑ること、扉の角の補正、窓・移動の間も時間とゴーレムが進むこと、窓の間の E、上下を向いたときの絵と足元、帯のランクが工房だけに出ること、がない | 設計どおりへの修正 | TC-FR-FLD-02-44〜46、TC-IF-08-57〜60 を足した（どれも合格） |
| R-04 | TC-FR-FLD-02-43 の「1 フレームで 7 単位」は手で確かめられない | 設計どおりへの修正 | 壁から壁まで歩く時間を ×1 と ×10 で比べる形にした |
| R-05 | TC-FR-FLD-01-40・41 の期待結果が具体的でない | 設計どおりへの修正 | 壁の端・屋根の段・名前の全文を書いた |
| R-06 | テスト仕様書の 3 章の記入者の書き方と余分な空行 | 設計どおりへの修正 | 直した |
| R-07 | 手動確認で、TC-IF-08-50 の期待結果の「／」区切りが DES-UI-11 と合わない（1 段上がる納品では「納品しました」が知らせに置き換わる） | 設計どおりへの修正 | 期待結果を DES-UI-11 に合わせた |
