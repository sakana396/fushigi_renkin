# 反復 5 計画書: 主人公を操作して、工房と街を歩く

- 文書 ID: IT05-PLAN
- 版: 0.1（案。8 章は開発者の承認待ち）
- 作成日: 2026-10-15
- 期間の目安: 2〜3 週間（PLAN-001 3.3 の目安 1〜2 週間を超える。ui の場面の画面（`internal/ui/game.go` 約 950 行）を、地図と窓に分けて作り直すため）
- 入力: [反復 4 振り返り](../it04/retrospective.md)、[SRS-001](../../02_requirements/srs.md) v0.5（案）

## 1. 目的

今はボタンを押して場面を切り替える画面だが、アトリエシリーズのように主人公を操作して遊ぶ形にする。目標の見た目と操作は、スターデューバレーのような見下ろし型の 2D（E-95）。今のパッケージ構成（core と ui の分離）のまま作る。

反復 5 では、工房と街を歩ける地図にする。採取地と戦闘は今の画面のまま使う（E-96）。

## 2. 確かめたい仮説

| ID | 仮説 | 確かめ方 |
|---|---|---|
| H-11 | 主人公を歩かせて設備を使うと、ボタンの画面より「錬金術士として遊んでいる」と感じる | 30 分ほど遊んだあと、反復 4 の exe（残しておく）と遊び比べてもらい、「どちらで遊びたいか」と理由を選択式で聞く |
| H-12 | 設備まで歩く手間が、錬金・納品・ゴーレムの割り当ての繰り返しで面倒にならない | 設計で、よく使う設備の間の歩く距離の上限を決める（例: 錬金釜・在庫の棚・扉の間は 8 マス以内）。振り返りで実際の距離を示し、どの作業（錬金、納品、割り当て、売買）が面倒だったかを選択式で聞く |

## 4. 作らないもの

- 採取地を歩くこと、落ちている素材を拾うこと（採取地と戦闘は今の画面のまま）
- ワールドマップと街道（FR-RD-01〜03。S-08 は見送り）
- 依頼の取り下げ（S-09）、生産物の種類を増やすこと（S-10）。8 章 P-09 で決める
- 3 枚目以降の地図の追加、MOD で画像やタイルの種類を足すこと（FR-FLD-04 は今ある地図の変更まで）
- 施設を建てたときに地図の見た目が変わること（FR-TWN-07）
- 主人公の能力値、装備、会話、物語のイベント
- 音、アニメーションの凝った演出（歩くときの数コマの絵の切り替えまでにする）
- セーブとロード、タイトル画面

## 8. 開始前の決定事項

P-01〜P-03 は開発者が決めた（E-96）。P-04 以降は推奨の案（REV-043 で P-11〜P-13 を足した）。

| # | 論点 | 決定（案） | 他の案 |

| P-03 | 地図の作り方 | **定義データの文字の地図**（E-96）。TOML に文字で地図を書き（例: `#` は壁、`K` は錬金釜）、起動時に検証する（FR-MOD-04。規則は P-12） | 地図エディタ（Tiled）。コードに直書き |

### 設計で決めること

次は 8 章では決めず、設計書（DES-IT05）で決める。

- 位置の単位（1 マス = 何単位か）、主人公の当たり判定の大きさ、斜めに動くときの速さ
- タイルの大きさと拡大率、カメラ（ウィンドウは 1600×940。街を 30×20 マス・16px・3 倍で描くと高さが 960px になるので、2 倍にするかスクロールする）
- 窓を開いている間は移動のキーを受け付けないこと、窓を閉じたときの位置と向き
- 上の表示（お金、時刻、時間の倍率、操作結果、ランクの知らせ。DES-UI-06・11）を地図の画面でどう出すか
- F12（チート）と F11 の案内の表示
- よく使う設備の間の歩く距離の上限（H-12）
