# 反復 5 計画書: 主人公を操作して、工房と街を歩く

- 文書 ID: IT05-PLAN
- 版: 0.1（案。8 章は開発者の承認待ち）
- 作成日: 2026-10-15
- 期間の目安: 2〜3 週間
- 入力: [反復 4 振り返り](../it04/retrospective.md)、[SRS-001](../../02_requirements/srs.md) v0.5（案）

## 1. 目的

今はボタンを押して場面を切り替える画面だが、アトリエシリーズのように主人公を操作して遊ぶ形にする。目標の見た目と操作は、スターデューバレーのような見下ろし型の 2D（E-95）。今のパッケージ構成（core と ui の分離）のまま作る。

反復 5 では、工房と街を歩ける地図にする。採取地と戦闘は今の画面のまま使う（E-96）。

## 2. 確かめたい仮説

| ID | 仮説 | 確かめ方 |
|---|---|---|
| H-11 | 主人公を歩かせて設備を使うと、ボタンの画面より「錬金術士として遊んでいる」と感じる | 30 分ほど遊び、反復 4 の画面と比べた感想を記録する |
| H-12 | 設備まで歩く手間が、錬金・納品・ゴーレムの割り当ての繰り返しで面倒にならない | 繰り返しの作業で面倒と感じた場面があったかを記録する |

## 3. 対象の要求

| 区分 | 要求 ID | この反復での扱い |
|---|---|---|
| フィールド | FR-FLD-01 | 工房と街の地図（地形と設備の配置）を持つ |
| フィールド | FR-FLD-02 | 主人公は壁や設備を通り抜けない |
| フィールド | FR-FLD-03 | 工房の扉から街へ、街の出口から採取地の一覧へ移れる |
| フィールド | FR-FLD-04 | 工房と街の地図を、定義データ（文字の地図）で書く |
| 画面 | IF-08 | キーボードで主人公を動かし、設備の前で決定のキーを押すと、その設備の機能（今の錬金・ゴーレム・店・依頼板などの窓）を使える |
| 画面 | IF-06 | 場面の行き来を、タブから地図の出入り口に変える（K-08） |
| 制約 | CST-04 | 画像素材の出典と利用許諾を記録する |

## 4. 作らないもの

- 採取地を歩くこと、落ちている素材を拾うこと（採取地と戦闘は今の画面のまま）
- ワールドマップと街道（FR-RD-01〜03。S-08 は見送り）
- 依頼の取り下げ（S-09）、生産物の種類を増やすこと（S-10）。8 章 P-09 で決める
- 主人公の能力値、装備、会話、物語のイベント
- 音、アニメーションの凝った演出（歩くときの数コマの絵の切り替えまでにする）
- セーブとロード、タイトル画面

## 5. 規模の目安

| 項目 | 数 |
|---|---|
| 地図 | 2 枚（工房: 約 20×12 マス、街: 約 30×20 マス） |
| 設備 | 工房: 錬金釜、在庫の棚、ゴーレムの作業台、施設の看板。街: 店、依頼板、施設を建てる看板（今の窓をそのまま開く） |
| 出入り口 | 工房⇔街、街→採取地の一覧 |
| 画像素材 | 地面・壁・設備のタイル、主人公（4 方向・歩く絵 2〜4 コマ） |

## 8. 開始前の決定事項

P-01〜P-03 は開発者が決めた（E-96）。P-04 以降は推奨の案。

| # | 論点 | 決定（案） | 他の案 |
|---|---|---|---|
| P-01 | 歩ける範囲 | **工房と街**（E-96）。採取地と戦闘は今の画面 | 工房だけ。採取地まですべて |
| P-02 | 主人公の位置と移動の置き場 | **core に持つ**（E-96）。地図・当たり判定・移動を core で tick ごとに計算し、単体テストで確かめる（NFR-04、DES-TIME-01） | ui だけで扱う |
| P-03 | 地図の作り方 | **定義データの文字の地図**（E-96）。TOML に文字で地図を書き（例: `#` は壁、`K` は錬金釜）、起動時に検証する（FR-MOD-04） | 地図エディタ（Tiled）。コードに直書き |
| P-04 | 画像素材 | **a. Kenney の CC0 の素材（例: Tiny Town。16×16 の見下ろし型のタイル。配布元のページで CC0 1.0 と確かめた）を使う**。人物の素材は、同じ作者の CC0 の素材から選ぶ。CC0 は再配布でき、クレジットも要らないので、公開リポジトリに入れられる。出典は記録する（CST-04）。素材を取り込む前に、利用許諾を配布元で確かめる | b. itch.io などのフリー素材（スターデューバレーに近い絵柄が多いが、再配布の禁止やクレジットの条件が素材ごとに違う）。c. 色の四角で仮置き |
| P-05 | 移動の仕方 | **a. 自由移動**（スターデューバレーと同じ。マスより細かい単位で動き、壁とはマス単位でぶつかる）。WASD と矢印キー | b. マス単位の移動（1 マスずつ滑らかに動く。作りやすい） |
| P-06 | 設備の使い方 | **a. 設備の隣で向いて、決定のキー（E かスペース）で今の窓（錬金、ゴーレム、店、依頼板など）を開く。Esc で閉じる。窓の中はマウスで操作する（IF-01）** | b. 設備に触れたら自動で窓を開く |
| P-07 | 場面の移動 | **a. タブをなくし、工房の扉と街の出口を歩いて通る。採取地の一覧は今の画面を開き、戻ると街の出口に立つ** | b. タブも残す |
| P-08 | 時間 | **a. 歩いている間も、窓を開いている間も、ゲーム内の時間は進む（ゴーレムは働き続ける）。F11 の倍率は今のまま** | b. 窓を開いている間は止める |
| P-09 | S-09・S-10 の扱い | **a. 反復 5 では扱わない（主人公の操作に絞る）。反復 6 の候補にする** | b. 依頼の取り下げ（S-09）だけ入れる。c. 両方入れる |
| P-10 | 実装の担当 | **Codex が実装し、spec-reviewer がレビューする。ui の手動テストは別のエージェントが Windows 版で行う（反復 4 と同じ）** | Claude Code が起こす別のエージェントが実装する |
