# 反復 1 計画書: プロトタイプ

- 文書 ID: IT01-PLAN
- 版: 0.1（ドラフト）
- 作成日: 2026-10-14
- 期間の目安: 2 週間

## 1. 目的

ゲームの核である「素材 → 錬金 → 製品 → 自動化 → 拡大」のループが面白いかを、最小の実装で確かめる。

## 2. 確かめたい仮説

| ID | 仮説 | 確かめ方 |
|---|---|---|
| H-01 | 製品が別の製品の素材になる連鎖と、ゴーレムによる自動化で、「作れる物と生産量が広がる」気持ちよさが出る | 15 分ほど遊び、「次はあれを自動化したい」と思うかを振り返りに記録する |
| H-02 | 自動品（平均・切り捨て）と手作り（平均を上回れる）の品質の差が、手で作る動機になる | 手作りを使う場面が自然に生まれたかを記録する |
| H-03 | 品質 1〜200 と属性 3 個までなら、素材選びがストレスにならない | 素材を選ぶときに迷った時間と、迷った理由を記録する |
| H-04 | 定義データ（本体＝組み込み MOD）からアイテムとレシピを読む構成で、無理なく作れる | 本体のデータを追加・変更する手間を記録する |

### P-01 の候補

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| a. 最高値寄せ | 手作りでは、平均ではなく「平均と最高品質の素材の中間」になる | 単純で分かりやすい | 工夫の余地が少ない |
| b. 触媒 | 手作りのときだけ、触媒を追加で入れられる。触媒の種類で品質に加算する | 「何を足すか」の選択が生まれる | 触媒という概念が増える |
| c. 属性の組み合わせ | 素材の属性（最大 3 個）の組み合わせが条件を満たすと、品質にボーナス | アトリエらしい発見がある | 調整が難しい。素材選びのストレス（E-17）に戻る恐れ |
