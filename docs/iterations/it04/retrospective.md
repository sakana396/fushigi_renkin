## 5. 進め方の振り返り

### うまくいったこと

- 反復 3 の振り返りで足した「初めて遊ぶ人が、操作の結果を画面から読み取れるか」の観点の手動テストで、仕様どおりでも分かりにくい点（知らせが次の操作で消える、倒れたユニットの HP0 が見えない など）を、開発者が遊ぶ前に洗い出せた（REV-040 U-1〜U-5、REV-041 U-1〜U-7）
- core の Issue（#67〜#69）で、レビュー担当がミューテーションを試し、テストの穴（35 通り中 7、58 通り中 14、43 通り中 7）を見つけて直せた。Claude Code も変異を 1 つずつ手で入れて再確認した
- データの Issue（#70）で、本体データで探索に勝てる操作と体力の推移をテストにした（TC-FR-MOD-02-47・48）。データの釣り合いを数字で確かめられた
- ui の Issue（#72）を #71 のブランチの上で先に進め、レビューと Windows の手動テストを並行させた。#71 のマージ後に main を取り込むだけで済んだ
- Codex は反復を通して使えた（E-88 のとおり、サブスクリプションで復活した）

### うまくいかなかったこと

| 問題 | 対策 |
|---|---|
| Codex が書いた ui の手動テストは、期待結果をぼかしていたり（「表示名が出る」）、アイテムの効果と倒れたことを見る場面が抜けていたりした。知らせのレシピが区別できない点や、倒れた出来事で関係のないマスが光る点は、ケースのとおりに試すだけでは見つからなかった（REV-040 R-01・R-02、REV-041 R-01・R-03） | 手動テストの期待結果は、画面に出る文と強調するマスを具体的に書く。レビューで期待結果を本体データから導いて確かめる |
| 手動テストの途中で修正のコミットが入り、どの版で確かめたかを分けて書く必要があった | 修正の exe は別のフォルダに作り、手動テストには版（コミット）を明記させる。終わったらスクリーンショットとテスト用の exe を片付ける |

## 6. 反復 4 で残した軽微な点

遊んで気にならなかったもの。ワールドマップで画面を作り直すときに、まとめて見直す。

- データの釣り合い（REV-039 D-1〜D-6）: ランク 1 の依頼だけでランク 4 に届く、森の戦闘の余裕が小さい、F12 ではランクが上がらない など
- ランクの画面（REV-040 U-1〜U-4）: 解放の知らせが次の操作で消える、解放される物が多いと知らせが右端で切れる、採取地と戦闘でランクが見えない、依頼ごとの評判の増え方が依頼板に出ない
- 戦闘の画面（REV-041 U-1〜U-7）: 倒れたユニットの HP0 が見えない、出来事の文にその後の体力がない、盤面に座標の目盛りがない、押せないボタンが灰色にならない、操作結果の欄の文が二重になる、負けた記録の最後のページが 1 行だけ、今の番と強調の色が近い
- 品質の進み方が探索に頼る、探索で稼ぐ量（REV-034 I-01〜I-03）
